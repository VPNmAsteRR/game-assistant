# MineBuddy — комплект

Готовый дистрибутив для установки на другой ПК.

## Что отдавать клиенту

**`MineBuddy-комплект.zip`** (в корне `game-assistant/`) — внутри:

```
MineBuddy-1.0.0-portable.exe   приложение (оверлей), 70 МБ
mods/minebuddy-bridge-1.0.0.jar  мод для Minecraft
УСТАНОВКА.md                     инструкция для пользователя
```

Пользователь: распаковал → закинул `.jar` в `mods` → запустил `.exe`. Всё.

## Требования на том ПК

- Windows 10/11 x64
- Minecraft **1.21.1** + **Fabric Loader** + **Fabric API**
- Больше ничего

## Исходники

```
app/      Electron-приложение (оверлей + мост)
mod/      Fabric-мод (сборка событий)
overlay/  исходная HTML-версия оверлея (для браузера/OBS)
dist/     артефакты сборки приложения
release/  содержимое готового комплекта
```

Пересборка:

```bash
# приложение
cd app && npm install && npx electron-builder --win --x64

# мод (нужен JDK 21)
cd mod && gradle build
```

## Про «localhost»

Связь мод ↔ приложение идёт через `127.0.0.1:47821`, но **пользователь её не настраивает**:
- мод сам поднимает сервер при входе в мир;
- приложение само к нему подключается и переподключается.

Наружу ничего не уходит, порт слушает только петлевой интерфейс.

## Что уже работает

- оверлей поверх игры (прозрачный, клики проходят в игру);
- приём событий из Minecraft: смерть, урон, голод, уровень, измерение,
  добыча руды, атака моба, мобы рядом;
- реакции на события: фразы + смена эмоций + лента;
- трей, горячие клавиши, Lite-режим, авто-переподключение.

## Что нет (следующие этапы)

- распознавание речи и диалог;
- LLM-генерация вместо набора фраз;
- озвучка (TTS);
- готовые спрайты (сейчас CSS-заглушка — подхватятся из `assets/<id>/<эмоция>.png`).
